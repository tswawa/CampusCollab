# Security reports / 安全报告

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/tswawa/CampusTask/security/advisories/new). This channel is enabled for the CampusTask repository. Use public issues for ordinary bugs that do not expose a security weakness.

Report affected version, required role, reproduction steps and impact using synthetic records. Exclude passwords, session cookies, CSRF values, SMTP credentials, student identities and production databases. Do not publish an unpatched exploit with real institutional data in a public issue.

Operators control HTTPS, registration approval, backups, retention and updates. The application is a single-instance deployment. It does not claim FERPA/GDPR certification or institutional authority to recognize service hours.

中文：安全漏洞请通过[私密漏洞报告](https://github.com/tswawa/CampusTask/security/advisories/new)提交。用虚构资料描述版本、角色、复现和影响，不上传密码、Cookie、SMTP 凭据或真实数据库。普通功能问题可提交 Issue。部署方负责 HTTPS、账号审批、备份、保留策略与更新。
